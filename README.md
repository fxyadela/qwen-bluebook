# 大学生AI全场景使用指南

> 四年少走3000+小时“弯路”　·　13个校园任务的使用手册与实操指南

[![License: CC BY-NC-ND 4.0](https://img.shields.io/badge/License-CC%20BY--NC--ND%204.0-1a56db.svg)](LICENSE)

## 这是什么

如今，大学生几乎都意识到AI重要了，但对多数学生而言，不知道在什么场景下用、怎么用、用到什么程度算合适。

原因往往不是AI能力不足，而是缺少一套从具体需求出发的操作路径。查资料应该怎么问、写作业应该怎么拆、准备面试应该怎么练，这些问题的答案散落在各处，始终没有一份系统的参考。

所以，我们以千问APP作为产品使用示意，从大学四年最高频的真实需求出发，筛选出 13 个核心使用场景，覆盖入学适应、课业学习和求职规划三个阶段，并附上具体实操步骤，读者可直接将提问原文替换为自身情况，即可上手使用。

## 13 个场景

### 第一篇　入学与适应　`场景 01—04`

从一件小事开始，把千问放进课程、生活与校园协作。

- **01　管理课程资料** — 把课程大纲、评分要求和截止时间放进同一个项目，后续提问不再反复补背景。
- **02　处理校园日常问题** — 把英文邮件、成绩计算和师生沟通放进一次清楚的对话中。
- **03　管理每月生活费** — 用 Excel Skill 把预算、流水和月报放进同一份可继续编辑的工作簿。
- **04　策划社团迎新活动** — 先规划人数、场地、时长和预算，再把活动方案变成可执行流程。

### 第二篇　学习与研究　`场景 05—09`

从生成内容走向组织材料、检验理解并完成交付。

- **05　完成课程小组展示** — 把课程材料变成听众能跟上的演示逻辑，并让讲稿严格回到原文。
- **06　建立期末复习系统** — 把知识图谱、出题、评分、错因和再测串成同一条复习闭环。
- **07　制定考研冲刺计划** — 让 7 天计划根据周中表现自动进入补基础、稳固或提难三个分支。
- **08　准备毕业论文答辩** — 依次完成论文格式处理、答辩 PPT 和模拟提问，把临近答辩的任务串成闭环。
- **09　四六级背单词桌宠制作** — 用千问生成个性化桌宠应用，让间隔重复和桌面互动融入日常学习场景。

### 第三篇　发展与求职　`场景 10—13`

把选择、文书与申请任务变成可解释、可核对的流程。

- **10　规划毕业发展路径** — 通过分步访谈比较考研、考公、出国与就业，形成四象限图谱和备选方案。
- **11　优化求职简历** — 先锁定国内与欧美简历的版式规则，再通过多轮对话逐段打磨内容。
- **12　撰写定制化求职信** — 围绕目标岗位和真实个人材料完成四段式求职信，并在多轮修改中减少模板感。
- **13　搭建科研申请工作台** — 把个人档案、申请进度和阶段行动放进同一个本地工作台，随时刷新下一步。

## 每个场景怎么写的

十三个场景共用同一套结构，跟着做就能复现：

- **适合人群** — 什么情况下值得用这个场景
- **实操案例** — 任务与材料、验收标准，以及逐步操作截图；每一轮实际敲进千问的**指令原文**都单独列出，可直接复制
- **结果复盘** — 千问交付了什么，你需要自己确认什么
- **场景使用技巧** — 可套用的任务框架、可复用提示词模板、替换字段表、使用提醒

提示词模板里方括号 `【】` 标出的是可替换字段，换成你自己的课程、目标和资料即可。

## 使用边界

- 文中课程、成绩、活动、简历等案例材料为演示用途的虚构或脱敏数据，不代表真实个人信息，也不构成任何考试真题或命题趋势判断。
- 操作截图取自真实实测过程，界面中可见的本机路径、账号与任务名属于作者本人的工作环境。
- 千问 APP 仅作为产品使用示意，本仓库与阿里巴巴无隶属关系。
- 效率账本中的时间与金钱为实测记录加合理估算，供参考，不承诺可复现。
